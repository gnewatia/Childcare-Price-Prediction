# The Financial Cost of Motherhood: Predicting Childcare Expenses across America

•	Clustered U.S. counties using unsupervised learning techniques (K-Means, Hierarchical Clustering, BIRCH) based on socioeconomic and demographic factors.

•	Built predictive models using boosting methods (XGBoost, Random Forest, AdaBoost) to forecast childcare costs.

•	Identified key determinants of childcare expenses through feature importance analysis, driving insights into cost variations.
